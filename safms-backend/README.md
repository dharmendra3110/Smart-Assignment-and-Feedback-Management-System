# Smart Assignment & Feedback Management System (SAFMS)

A lightweight backend for managing assignments, submissions, feedback, and anonymous doubts between students and teachers — built with **Node.js** and **Express**, using a simple JSON file as a local database (no external setup required).

---

## 🚀 Features

- 👩‍🏫 Teacher and Student roles
- 📝 Create, submit, and grade assignments
- 💬 Post and reply to doubts (with optional anonymity)
- 🔐 JWT-based authentication
- 💾 JSON file-based data storage (no database installation)
- ⚙️ CORS enabled — easily connects with any HTML frontend
